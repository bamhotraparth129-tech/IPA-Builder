# Viper Snake (iOS / SwiftUI)

A SwiftUI Snake game for iPhone featuring swipe steering, combo multipliers, timed bonus pickups, toggleable portal walls, and persistent high scores.

## Build an `.ipa` via GitHub Actions

1. Open the **Actions** tab in this repository.
2. Select **Build ViperSnake IPA** and click **Run workflow**.
3. Once complete, download the `ViperSnake-ipa` artifact and extract `ViperSnake.ipa`.

## Sideload on iPhone

1. Sign `ViperSnake.ipa` with your Apple ID using **Sideloadly** (or another sideloader).
2. On your iPhone, trust the developer profile under **Settings > General > VPN & Device Management**.
3. Enable **Developer Mode** under **Settings > Privacy & Security > Developer Mode** (restart if prompted).

> Note: Free Apple ID sideloads expire after 7 days and require re-signing.
